The first published release of Noto.

This is an early build. The foundation — the editor, local storage on every
platform, and the release pipeline that produced these downloads — is in place
and working. Expect gaps, and expect them to close.

## Highlights

- **Desktop applications** for Windows, macOS and Linux, with automatic updates
  on Windows and macOS.
- **Web application** that runs in the browser with nothing to install and keeps
  working offline once loaded.
- **Local-first storage.** Documents live on your device — SQLite on the
  desktop, IndexedDB in the browser. No account, no server, no telemetry.
- **A rich text editor** built on ProseMirror: headings, lists, quotes, code
  blocks and inline formatting, with autosave.

## Known limitations

- Mobile applications are not published yet.
- Cloud sync is not enabled; `packages/sync` ships the contract and a local-only
  engine so it can be turned on later without a rewrite.
- The installers are **unsigned**. Windows SmartScreen and macOS Gatekeeper will
  warn on first launch until code-signing certificates are in place. Verify your
  download against `SHA256SUMS.txt` in the meantime.
- macOS auto-update requires a signed build, so it does not work in this
  release. Windows auto-update does.
- Windows ARM64 is installer-only and does not auto-update; a single Squirrel
  update feed cannot serve two architectures.
