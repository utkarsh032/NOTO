A prerelease that exercises the full release pipeline end to end before the
first stable version is published.

The application content is identical to what 0.1.0 will ship. What is being
proven here is the machinery: cross-platform packaging, artifact naming,
checksum generation, release-note composition, and publication to GitHub
Releases.

Because this is a prerelease it is not marked as the latest release, so the
download page on the website continues to show that no stable version has been
published yet. That is intentional.

See [0.1.0](0.1.0.md) for what the release itself contains, including its known
limitations — the installers are unsigned, and macOS auto-update needs a signed
build.
